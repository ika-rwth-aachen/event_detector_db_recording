Detailed Description

Component of the Event Detector responsible for database insertion.

As one of the three components of the Event Detector, the DatabaseInterface handles all connections to the MongoDB database. It is responsible for converting selected ROS messages to a database-compatible format and storing all data as defined per the database schema.
